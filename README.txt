HEARTHSTONE RECONNECTOR 4.1 — WINDOWS 11

ЗАПУСК
Закройте старую версию через трей. Распакуйте архив в отдельную папку.
Запустите HearthstoneReconnector.exe и подтвердите запрос администратора.
В активном окне игры видна кнопка с котом и следами когтей, без текста.
Нажимайте один раз во время боя в «Полях сражений».
В трее «Показать / переместить кнопку» включает режим перемещения:
жёлтая пунктирная рамка и стрелки, перетаскивание левой кнопкой мыши.
Повторный выбор пункта завершает режим; позиция сохраняется.

НОВЫЙ МЕХАНИЗМ
Вместо краткой блокировки пакетов выполняется точечное закрытие одного
установленного IPv4 TCP-соединения матча через SetTcpEntry.
Учитываются процесс Hearthstone, локальный IP/порт и удалённый IP/порт.
Прочие соединения игры не закрываются циклом и не блокируются новыми правилами.
Путь установки и адрес сервера определяются на компьютере пользователя.
Сначала выбирается единственное соединение на порт 3724; для другого порта
или нескольких соединений нужен подходящий адрес из игрового журнала.
При неоднозначности операция отменяется. Возможен выбор по устаревшему журналу:
подтверждение совпадения адреса с действующим сокетом снижает, но не исключает риск.

Старое соединение проверяется повторно непосредственно перед разрывом.
После разрыва до 12 секунд проверяются исчезновение старого TCP-соединения,
появление нового и свежая запись SERVER_GAME_STARTED в игровом журнале.
Зелёные царапины: новое TCP-соединение и запись восстановления матча найдены.
Жёлтые царапины: новое TCP найдено, восстановление матча по журналу не подтверждено,
либо ожидание отменено. Красные царапины: ошибка/истечение срока ожидания.
Повторное нажатие запрещено до завершения операции и ещё 12 секунд после неё.
Игра сама переподключается; приложение не воспроизводит бой и не управляет матчем.
Параметр длительности блокировки удалён: нового правила брандмауэра нет.
Исправлена UTF-8 кодировка обмена с помощником и записи сообщений в журнал.

ОГРАНИЧЕНИЯ
SetTcpEntry в этой версии поддерживает IPv4. При IPv6 приложение откажется
от разрыва с понятным сообщением. IPv6 в Windows не отключается.
Драйверы и неподдерживаемые системные функции не устанавливаются.
Нужны права администратора. Приложение предназначено для Windows 11 с .NET Framework 4.x.
Сторонняя защита может блокировать запуск неподписанного .exe или помощника.
Нет гарантии работы на всех ПК или отсутствия вылетов Hearthstone.
Точечный разрыв может по-прежнему выявлять ошибки самого игрового клиента.
Завершение TCP не гарантирует успешного возвращения в матч.
Журналы игры читаются только из папки Logs рядом с Hearthstone.exe; если нужного
журнала нет, подтверждение SERVER_GAME_STARTED недоступно.
Если кнопка не видна в эксклюзивном полноэкранном режиме, используйте оконный.
Не запускайте несколько реконнекторов одновременно.

ВОССТАНОВЛЕНИЕ И ДИАГНОСТИКА
Помощник выполняет один разрыв и ожидание. Новые правила брандмауэра не создаются.
При запуске удаляются остаточные правила прошлых версий с идентификаторами HSRC2.
RestoreConnection.cmd оставлен для удаления именно этих старых правил.
Трей → Открыть журнал. Данные: %LOCALAPPDATA%\HearthstoneReconnector\
Журнал включает CANDIDATE, DIRECT_BEGIN, SET_TCP_ENTRY result,
OLD_SOCKET_GONE, MATCH_RESTORED и ошибки. Для диагностики на другом ПК
передайте журнал после одного нажатия и опишите поведение игры.

ПРОВЕРКИ СБОРКИ
Проверены точное кодирование TCP-адресов/портов, отличие нового сокета от старого,
выбор соединения и отказ при неоднозначности, чтение IPv4/IPv6 таблиц,
UTF-8 обмен с отдельным процессом, подтверждение только по новым строкам журнала,
встроенная иллюстрация, ховер/нажатие и режим перемещения.
Настоящее закрытие TCP в тестовой среде пропущено из-за отсутствия повышенных прав.
Живой матч и работа на компьютере друга пока НЕ проверены.

СБОРКА
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
Исходники, иллюстрация и иконка включены. Иллюстрация встроена в .exe:
для запуска достаточно самого .exe; распаковка архива предпочтительна для инструкции.

ИЗОБРАЖЕНИЕ
Оригинальная иллюстрация создана встроенным ImageGen по идее пользователя:
кот с поднятыми лапами и красными следами когтей, золотая рамка и тавернное дерево,
в стиле fantasy collectible-card game / Hearthstone Battlegrounds, без текста.
Промпт сохранён в image-prompt.txt. Изображение из вложения использовалось как референс.

ВИЗУАЛЬНОЕ ОБНОВЛЕНИЕ 4.1
Окно использует попиксельную альфа-прозрачность (UpdateLayeredWindow):
снаружи золотой рамки нет тёмной подложки. Внутри рамки сохранено дерево.
Во время реконнекта кот по очереди царапает лапками; царапины пульсируют голубым.
После результата они пульсируют зелёным, жёлтым либо красным по состоянию.
Бегущая полоска и цветная рамка состояния убраны. Режим перемещения сохранён.
Слои предварительно уменьшаются до размера кнопки, чтобы анимация не задерживала ввод.
Проверены альфа-канал, разные кадры, цвета, клики, отмена клика, перемещение,
сохранение координат и реальный вызов UpdateLayeredWindow.
Повторная проверка чтения TCP-таблицы ограничена sandbox (Access denied).
Механизм реконнекта в 4.1 не изменён; живой матч не тестировался.
